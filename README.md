Repozytorium zawierające moje osobiste projekty związane z asystentami AI i agentami konwersacyjnymi. Projekty mają charakter **studencki/testowy/edukacyjny** i służą eksperymentowaniu z różnymi architekturami, modelami językowymi oraz technikami promptowania.
 
## 📚 

To miejsce, gdzie zbieram swoje eksperymenty z:
- Asystentami konwersacyjnymi (chatboty)
- Agentami AI z różnymi specjalizacjami
- Technikami walidacji i bezpieczeństwa promptów
- Integracjami z różnymi modelami LLM (lokalne i API)
- Architekturami wielomodelowymi

## 📖 Jak korzystać z projektów?
 
Każdy projekt ma własną dokumentację w swoim folderze. Ogólne kroki:
 
1. **Sklonuj repozytorium:**
   ```bash
   git clone https://github.com/Ololololololo-maker/AI_Agent.git
   cd AI_Agent
   ```
 
2. **Wybierz projekt:**
   ```bash
   cd Simple_AI_assistant  # lub inny projekt
   ```
 
3. **Przeczytaj dokumentację projektu:**
   ```bash
   cat README.md
   ```
